
# ⚡ Automatic Street Light using ESP32

## Project Overview
An automatic street light system using ESP32
and an LDR sensor.

## Components Used
- ESP32
- LDR sensor
- LED
- 220 Ohm resistor

## Working Principle
The LDR detects surrounding light intensity.

- Bright environment: LED OFF
- Dark environment: LED ON

## Technologies Used
- Arduino C++
- ESP32
- Wokwi Simulator

## Learning Outcomes
- GPIO programming
- Analog sensor reading
- Embedded systems
- Basic automation

## Simulation
Built and tested using Wokwi.
